# Takeoff-2024

Codebase for [Texas Torque](https://texastorque.org)'s 2024 competition robot.

## Subsystems

- Drivebase: swerve drive.
- Perception: vision processing with custom NVIDIA Jetson & three cameras.
- Intake: over the bumper full width intake.
- Shooter: chain driven rotary shooter with a gate & flywheels.
- Climber: custom climber tubes with constant force springs.
- Lights: led strip for driver signaling.
